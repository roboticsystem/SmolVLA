## 2. 五个硬欠账（P0 · 答辩必被追问）

### 2.1 定位精度：没有实验、没有指标、实现是骨架 🔴

| 项 | 内容 |
|---|---|
| **论文依据** | 论文2 第 3/4 章把定位作为**独立方法章**并给出成体系的量化结果：ChArUco 测距 **0.5 m→24.2 mm、2.0 m→33.8 mm、相对误差恒 <3%**；测角 **平均 0.6°、最大 ≤1.8°**；重投影误差 **MRE = 0.66 px**；Sigmoid 自适应 EKF 使**定位误差 7.8→5.1 cm（−34.6%）、最大误差 17.6→9.3 cm（−47.1%）、离群帧抑制率 91.5%、单帧附加耗时仅 0.21 ms**；因子图方案**常规工况 RMSE ≤ 3.7 cm**，且**相机被遮挡 4 s 恢复时无位姿阶跃** |
| **我方现状** | `SmolVLA/ros2_ws/src/vla_nav/vla_nav/odom_node.py` 文件头自述「**本文件是骨架**」：扫描匹配**只在 ±0.05 m 内做 5 点网格搜平移、完全不估旋转**，注释里留着 `TODO(真机)：换成 ICP 或相关性扫描匹配（CSM）`。全项目**没有任何一个位姿误差数字**，也没有定位误差对导航结果的敏感度分析 |

### 3.1 能耗/续航模型（论文3 全篇主线）★ 最高价值

| 项 | 内容 |
|---|---|
| **论文3 怎么做的** | ① **三段拆解**：驱动行驶 / 差速转向（减速-旋转-加速，制动并入转向段）/ 待机与辅助（主控+通信+BMS 恒定待机 + 传感器按需激活）；<br>② 行驶能耗：`F = (m₀+m_load)a + (m₀+m_load)gμ_r + ½ρC_dAv²`，`E = ∫F·v dt / η(v)`，效率 η(v) 三段非线性（低速铜损主导 → 中速高效区 → 高速弱磁铁损）；<br>③ 转向能耗：`E ∝ k_转向 · (1 + β·m_total) · k_角度 · |Δθ|^n`，**n>1 超线性惩罚**，结论「**两次 45° 的总能耗 < 一次 90°**」；<br>④ **U 型经济时速**曲线（存在最优经济速度，不是越快越好）；<br>⑤ 辅助能耗占匀速总能耗 **8%–12%** |
| **怎么降到单机 VLA** | 三段 → **底盘驱动 + 转向 + BPU 推理 + 传感器待机**（VLA 场景里「算力即能耗」是真实约束）；<br>**U 型经济时速** → 支持「动作平滑 + 合理控制频率」的设计取向；<br>**转向超线性** → 支撑 E4 的「转向代价/动作平滑」项；<br>**SOC<20% 熔断卸载**（论文3 调度侧） → 跟随任务「电量低时停止接单/返航」 |
| **我方现状** | 有部署指标（功耗、SoC 温升、续航）与电池规格（7.4 V / 3000 mAh），但**没有模型**，也没把「算力预算」换算成「能耗预算」——大纲 §2.2 只算到 150 GOPS，没换算到 W / mAh |
| **建议补法** | 新增 **E6b**：四段能耗分解 + **实测标定**（电机端电压电流、BPU 推理功耗、传感器功耗）+ 「单帧推理功耗 → 可持续帧率 → 续航」推算 + 与理论值对比 |

### 3.2 拥挤度量化（论文4 §2.1）

| 项 | 内容 |
|---|---|
| **论文4 怎么做的** | 拥堵度 = **半径 r（=2.5 m）内 AGV 局部占用率** × **意图权重**：载货点处空载车 0.6（准备离开）、载货车 1.0（要在此装货→加压）；卸货点反之。拥堵参数 = 加权代价 / 范围内车辆数，w≈0 为空、接近 1 为极拥堵，**超阈值触发干涉** |

### 5.1 绪论缺「现有技术的局限性分析」节

1. VLA 推理延迟与底盘控制频率的**结构性冲突**（→ 主创新 B 的存在理由）；

4. **仿真—实机外推缺乏量化链条**（→ E12 的立论，四篇全无）。

并给出可被检索的空白句式，例如：「面向**室内跟随**任务的 **VLA 端侧部署与可量化仿真—实机一致性闭环**研究相对有限」。

### 5.2 方法章与实验章之间的「章内自证」

论文3 的**模型章自带「能耗模型验证」小节**（哪怕只是数值仿真 + 可视化），而不是把验证全推给实验章。我方第 4/5 章几乎每节都依赖后续实验章兜底。
→ **改法**：每个方法小节至少给一个**章内自证**（形式化性质、可行性边界、复杂度、标定曲线）。

### 5.3 超参取值依据与敏感性

论文2 给 h（多头数）与 τ（目标网络步数）的敏感性表；论文4 给 r=2.5 m、意图权重 0.6、λ₁=3/λ₂=4 的取值来源（算例 + 参数表）；论文3 给归一化方式（Min-Max）与权重和约束。
