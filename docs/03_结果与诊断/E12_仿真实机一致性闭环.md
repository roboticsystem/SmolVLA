# E12 仿真—实机一致性闭环（P5）

> 对应论文实验编号 **E12**（四篇参考论文都有、而本项目此前缺的一环）。
> 目标：把「仿真结论能不能外推到实机」从一句口号变成**可量化、可复现、可写进论文**的证据链。
> 代码：`sim/replay.py`、`sim/sim2real.py`、`scripts/real/sim2real_report.py`、`scripts/real/make_mock_recording.py`。

## 1. 轨迹重放误差：真机指令 → 仿真执行

`sim/replay.py :: replay_in_sim(rec, env)`

把真机录到的**动作序列**在仿真里重放，比较两条轨迹。

三个必须处理的口径问题（处理不好，指标就没有意义）：

1. **坐标系不可比**。真机里程计的原点是「开机那一刻的位置」，与仿真坐标系毫无关系。
   若直接相减，测到的会是「坐标系差异」而不是「动力学差异」。
   → 统一在**刚体对齐（2D 旋转 + 平移，Umeyama 最小二乘）后**统计误差，
   未对齐的原始值单独列出（`pos_rmse_raw`）备查。
2. **对齐会吸收常量偏差**，所以「起点差了多少」必须单独报（`init_offset`）。
3. **不能拿真值轨迹去比里程计轨迹**。里程计本身有偏（轮滑、漂移都表现为位姿误差）。
   → 提供两种参考口径（`ref`）：
   - `ref="gt"`：与**地面真值**（录制里的 `gt_pose`）比 —— 最干净，差异全部来自动力学；
   - `ref="odom"`：与**里程计**比 —— 只有里程计时唯一可选。

### 1.1 两层误差归因

| 口径 | 做法 | 测到的差异 |
|---|---|---|
| `mode="command"` | 指令序列 → 仿真完整动力学 | **动力学差异 + 里程计偏差** |
| `mode="measured"` | 绕过仿真动力学，用真机**实测速度**积分位姿 | **纯里程计偏差**（真机侧固有，仿真消除不了） |

两者相减 ≈ **可归因于动力学的部分**（`error_budget["dyn_part"]`）。

### 1.2 误差预算分解（逐项消融）

`sim/sim2real.py :: error_budget`

- 基线：无任何退化的仿真重放 → RMSE₀
- 逐项：只开第 i 项退化 → RMSEᵢ，**误差解释量** = RMSE₀ − RMSEᵢ
  （>0 = 该退化确实存在于真机；<0 = 真机上没这个现象，仿真里加它反而更差）
- 全开：所有退化同时开 → RMSE_all
- 残差 = RMSE_all − RMSE₀ + Σ 解释量（交互项 + 未建模因素）

消融项与 `sim/env.py` 的退化开关一一对应：

| 预算项 | 仿真开关 | 物理含义 |
|---|---|---|
| 加减速斜坡 | `accel` / `acc_ang` | 电机 + 惯量，速度不能瞬变 |
| 轮滑 | `slip` | 湿滑/地毯，实际位移打折 |
| 执行器延迟 | `act_delay` | 串口/网络排队，动作延后 k 步生效 |
| 里程计漂移 | `odom_drift` | **只污染上报位姿**，真值轨迹不变 → 不进开环轨迹误差，单列到闭环口径（§2.3） |

## 2. 动力学参数标定

`sim/sim2real.py :: fit_kinematics`

| 拟合量 | 定义 | 仿真侧换算 |
|---|---|---|
| `motor_gain_v/w` | 实测速度 = gain × 指令速度（电机标定） | 仿真默认 1.0（指令即速度） |
| `tau_v/w` | 一阶滞后时间常数（`v' = v + (cmd−v)·dt/τ`） | `accel ≈ v_max/τ`（=0.35/τ） |
| `drift_m_per_m` | 里程计自洽性：上报位姿 vs 由上报速度积分的位姿 | `odom_drift` |
| `odo_bias` | 里程计偏差 = 上报路径 / 真值路径（**需独立真值**） | `slip`：1 − 0.35p = 1/bias |

### 2.1 可辨识性（必须写进论文的诚实说明）

**只含里程计的录制里，轮滑与里程计漂移不可分辨** —— 里程计既不测「轮子转了多少」
也不测「车实际走了多远」，两者都以「位姿误差」的形式混在一起。
要分离必须引入**独立真值**（AprilTag / 视觉定位 / 动捕），即录制里的 `gt_pose`。
有真值时给出 `odo_bias` 与等效滑移概率；没有真值时明确标注**不可辨识**并给区间。

### 2.2 网格搜索标定

`fit_dynamics_grid(rec, env)`：在 (accel × slip × act_delay) 网格上找**回放误差最小**的组合。
这是把上面三个量真正分开手段（给定真值轨迹后，误差判据就把它们区分开了）。

### 2.3 闭环口径

`closed_loop_impact(env, policy, episodes)`：同一策略、同一批回合种子，逐项打开退化，
比较 SR/SPL 的变化。这是**里程计漂移唯一能被量化的地方** ——
它不影响真值轨迹，但会误导**消费上报位姿的策略**（VLA 就是这种）。
（注意：使用真值位姿的特权基线 `geodesic`/`oracle` 不受漂移影响，实测 ΔSR = 0，
这本身也是一个有意义的结论 —— 漂移只惩罚「依赖里程计的策略」。）

## 3. 观测域差（图像 + 激光）

`sim/replay.py :: domain_gap(rec, env)`

把真机轨迹**锚定到仿真出生点**（`anchor="spawn"`：真机起始位姿对齐到仿真出生位姿，
相对运动原样搬过来），再在仿真里渲染同位姿的观测，逐项比较统计量：

- 图像：亮度均值 / 对比度 / 饱和度 / **边缘密度** / 暗像素占比 / 过曝占比
- 激光：平均距离 / P10 / P50 / P90 / 命中占比 / 近距回波占比

两个必须做的处理：
1. **分辨率对齐** —— 真机 640×480 vs 仿真 160×120，边缘密度随分辨率变化，
   必须双线性重采样到同一分辨率才可比。
2. **锚定** —— 不锚定的话，真机坐标多半落在仿真场景外，
   图像全是墙、激光全是 12 m，统计毫无意义。

域差是**域随机化强度的依据**：仿真亮度比真机低 10、边缘密度只有真机的 1/3
这类结论，直接指向该加什么随机化（对比度/纹理/噪声），而不是笼统地说「缩小差距」。

## 4. 等效密度换算（论文4 范式）

`sim/sim2real.py`

论文4 的对应关系：实机 6 辆 AGV / (3 m × 2 m) ↔ 仿真 80~100 辆 / (75 m × 45 m)，
**空间密度相同**；再比较两边的死锁趋势，报**误差率**（表 29）。

本项目把它映射到导航场景：

- **实机侧**：部署规模 N_real、场地面积 A_real → 密度 ρ_real = N_real / A_real
- **仿真侧**：场地面积 A_sim → **等效规模** N_sim_equiv = ρ_real × A_sim
- **拥挤度**：`scene_density(scene)` 给出 ρ_occ（障碍占地比）、自由面积占比、
  语义目标密度（个/m²）、房间数 —— 这些量在实机场景里同样可以量（现场标定/照片估计），
  是「仿真场景像不像真场景」的直接度量。
- **误差率**：`density_error_rate(sim_value, real_value)` = |仿真 − 实机| / 实机
  （论文4 表 29 口径；实机为 0 时退化为绝对差）。

## 5. 使用方式

### 5.1 有真机数据时

```bash
# ① 真机采数（小车端）
python3 deliver/tools/record_dataset.py --ros --out deliver/data_recorded/session.h5 \
    --instruction "去箱子旁边"

# ② 回工作站生成一致性报告
python3 scripts/real/sim2real_report.py \
    --h5 deliver/data_recorded/session.h5 \
    --layout apartment \
    --closed-loop --policy geodesic --episodes 20 \
    --real-n 1 --real-area 6.0 --real-sr 0.80 \
    --out export/sim2real/session.md --json export/sim2real/session.json
```

产出 Markdown 报告七节：轨迹重放误差 / 图像域差 / 激光域差 / 动力学标定 /
误差预算 / 闭环影响 / 等效密度换算。

### 5.2 没有真机数据时（验证管线本身）

```bash
python3 scripts/real/make_mock_recording.py --out /tmp/mock.h5
python3 scripts/real/sim2real_report.py --h5 /tmp/mock.h5 --layout apartment \
    --out export/sim2real/mock.md
```

`make_mock_recording.py` 用仿真造一段**与真机同 schema** 的录制，并**故意注入**
一阶滞后 τ、轮滑增益 gain、里程计漂移 drift、图像亮度/噪声偏移、激光测距噪声与丢束。
它的作用是**在接真机之前就把整条链路的口径、字段名、单位、符号跑通**。

## 6. 端到端验证结果（样例录制，已知真值）

注入的不完美：τ = 0.45 s、gain = 0.82（轮滑）、drift = 0.012 m/m。

| 指标 | 注入真值 | 实测拟合 | 结论 |
|---|---|---|---|
| 一阶滞后 τ_v | 0.45 s | **0.420 s** | ✓ 数量级与量值都对 |
| 一阶滞后 τ_w | 0.45 s | **0.413 s** | ✓ |
| 里程计偏差 odo_bias | 1/0.82 = **1.2195** | **1.2180** | ✓ 误差 0.13% |
| 等效滑移概率 | (1−0.82)/0.35 = 0.514 | **0.511** | ✓ |
| 里程计自洽性漂移 | 0.012 m/m（随机游走） | **0.0149 m/m** | ✓ 同量级（含积分误差） |
| 等效加减速 | 0.35/0.45 = 0.78 m/s² | **0.832 m/s²** | ✓ |

误差预算（参考口径 = 地面真值）：

| 预算项 | 位置误差 RMSE (m) | 误差解释量 | 占基线 |
|---|---|---|---|
| 真机侧：里程计口径 | 0.071 | — | — |
| 基线（无退化） | 0.088 | — | — |
| 加减速斜坡 | 0.102 | −0.013 | −15.3% |
| 轮滑 | 0.065 | **+0.023** | 26.0% |
| 执行器延迟 | 0.054 | **+0.034** | 38.4% |
| **全开（组合）** | 0.054 | +0.034 | — |
| 残差（交互 + 未建模） | 0.009 | — | — |

解读：基线误差 0.088 m 里，**轮滑 + 执行器延迟两项解释了约 49%**（Σ解释量 0.043 m），
残差仅 0.009 m；「加减速斜坡」单独开反而变差，是因为它与「执行器延迟」都描述
**同一段速度爬升过程**（不是正交项），这一重叠由残差项显式承担 —— 论文里必须这样写，
否则会被追问「为什么两个项重复计数」。

闭环口径（`geodesic` 上界，公寓户型，20 回合，同一批种子）：

| 退化项 | SR | SPL | ΔSR |
|---|---|---|---|
| 无退化 | 90.0% | 0.900 | — |
| 加减速斜坡 | 80.0% | 0.800 | −10.0 pp |
| 轮滑 | 85.0% | 0.850 | −5.0 pp |
| 执行器延迟 | 70.0% | 0.700 | −20.0 pp |
| 里程计漂移 | 90.0% | 0.900 | ±0.0 pp |

（`geodesic` 用真值位姿，故不受里程计漂移影响 —— 漂移只惩罚**依赖里程计的策略**，
这正是 VLA 与特权基线的差别所在。）

## 7. 论文里可以怎么写（建议表述）

> **E12 仿真—实机一致性闭环。** 为检验仿真结论的外推性，本文构建了
> 「真机录制 → 仿真重放 → 域差量化 → 参数标定 → 误差预算 → 等效密度换算」的闭环。
> 在**轨迹层面**，采用 2D 刚体对齐消除坐标系不可比性后，指令重放的位置误差 RMSE 为
> X cm（对齐前 Y cm）；进一步用「实测速度回放」把真机侧固有的里程计偏差（Z cm）
> 与可归因于动力学的部分分离，并对加减速斜坡 / 轮滑 / 执行器延迟三项做**逐项消融**，
> 得到误差预算：三项合计解释基线误差的 P%，残差 Q%。
> 在**观测层面**，将真机轨迹锚定到仿真出生点后同位姿渲染，比较图像亮度/对比度/边缘密度
> 与激光距离分布，量化出仿真与真机的域差，为域随机化强度提供依据。
> 在**场景层面**，沿用文献[论文4]的等效密度换算范式：以实机部署密度 ρ_real 换算出
> 仿真场地的等效规模 N_equiv，并在等效密度下比较任务指标，报告误差率 E%（文献[论文4]表29 口径）。
> 需说明的是：仅含里程计的录制无法区分轮滑与里程计漂移，本文通过引入独立真值
> （外部定位）分离二者，未引入真值时该项标注为不可辨识。

## 8. 已知边界与后续

1. **样例录制 ≠ 真机数据**：§6 的数字是「管线自检」的结果（注入真值 → 拟合值），
   证明的是**测量方法正确**，不是仿真对真机的真实精度。真实精度必须等实机录制接入后重测。
2. **地面真值尚未接入真机**：`gt_pose` 目前只由样例录制生成。
   实机侧建议用 AprilTag/视觉定位额外记录一路位姿，才能分离轮滑与里程计漂移。
3. **场景几何对齐**：当前是「固定户型 + 轨迹锚定到出生点」。
   真机若在非标房间拍摄，需要额外做一次**场景配准**（语义地图对齐）才能让域差统计成立。
4. **域随机化反哺**：域差统计的输出应直接接到 `sim/env.py` 的
   `camera_augment` / `light_*` / `gloss` 等参数上，形成「测量 → 调参 → 再测量」的闭环；
   这一步尚未自动化（当前需人工按报告调参）。
